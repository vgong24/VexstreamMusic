# VexStream Music brand assets

`[VXG RealForever]`

This directory preserves two different visual responsibilities instead of collapsing them:

- `vexstream-music-logo.png` is the canonical full-resolution VexStream Music visual for repository, documentation, presentation, and showcase use.
- `vexstream-music-approved-original.webp` preserves the approved generated source visual unchanged for future re-export or wider-audience use.
- `vexstream-music.ico` is the Windows application-icon derivative. It is intentionally multi-resolution and must not replace the full visual source.

The application icon may be re-exported from the canonical full visual when Windows rendering requirements evolve. The full visual remains the source-facing brand asset.
