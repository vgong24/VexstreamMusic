# 1.1.6 — filtered Songs playback regression repair

`[VXG RealForever]`

## User-visible defect

In 1.1.5, starting a song while the Songs view had a search or genre filter active caused playback to operate only on the visible result set. A two-result search could therefore leave the persistent player queue with only two tracks even after the search was cleared.

## Exact 1.1.5 cause

The recovered 1.1.5 UI defined:

```text
baseFilteredTracks()
  -> applies search + genre filter to state.tracks

sortedSongTracks()
  -> sortTrackList(baseFilteredTracks())

playLibraryTrack(id)
  -> Songs playback context = sortedSongTracks()
  -> setQueue(filteredContext, selectedIndex, true)
```

The display projection and the playback context were therefore the same object by construction.

## 1.1.6 invariant

The Songs page now keeps its visible filter behavior while playback resolves against the full sorted `state.tracks` collection.

With shuffle disabled, the existing full-library ordering semantics and selected index are preserved.

With shuffle enabled, the selected track is moved to queue index `0` before `setQueue(...)`. The existing queue shuffler then randomizes only the future portion, so:

```text
current = selected track
future  = every other library track, shuffled
```

No filtered-out song is lost from the shuffle universe.

## Queue boundary

The per-row `Add to queue` action remains separate from playback-context formation. Clicking it appends that one selected track. Bulk queue operations still use the user's explicit selection. This repair does not reinterpret a search result as an instruction to enqueue the whole library.

## Regression coverage

`tests/ui-queue-regression.test.mjs` proves:

1. filtered Songs + non-shuffle playback receives the full library;
2. filtered Songs + shuffle starts on the chosen song and contains every library song exactly once;
3. Home / recent-track playback behavior remains unchanged;
4. row-level Add to queue remains a one-track action;
5. the recovered UI reports 1.1.6 while retaining the filter implementation.
